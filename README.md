# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 写闸口径

全局只采纳一种架构：**互证一致即封印当日写**。

- 营业日内只要存在一条 `status='一致'` 的互证流水，当日即封印。
- 封印只挡三个写入口：迁移完成、保留销毁、分区登记；只读总览与各列表照常可用。
- 判定由 `verify_runs` 流水重放（`GET /api/写闸探针`），不存额外状态位；总览内嵌同一份结论。
- 解封/复封杠杆是营业日：切到当日尚无一致流水的一天即解封，切回会重新封印。
- 写入口的闸判定与实际写入在同一 `BEGIN IMMEDIATE` 事务内，被拒时连半截写一并回滚。
- 片库容量闸不在本口径内，另立需求。
